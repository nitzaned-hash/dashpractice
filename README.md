# דאשבורד פניות שירות לקוחות

דאשבורד סטטי (HTML/CSS/JS בלבד, ללא צורך בהתקנת Node/Python/npm) להצגת פניות שירות לקוחות: KPIs, גרפי מגמה, טבלת פניות עם סינון וחיפוש, וביצועי נציגים. כרגע מוזן בנתוני דמו (220 פניות מדומות ב-45 הימים האחרונים) — כשתרצו, אפשר לחבר נתונים אמיתיים (ראו בסוף).

## מבנה הפרויקט

```
dashpractice/
├── index.html          עמוד הדאשבורד עצמו
├── css/styles.css       כל העיצוב (כולל מצב כהה)
├── js/data.js            נתוני הדמו — כאן משנים/מחליפים נתונים
├── js/charts.js          גרפי SVG פנימיים (קו, עמודות, דונאט) — ללא ספריות חיצוניות
├── js/app.js              הלוגיקה: סינון, KPIs, טבלה, מודאל פרטים
├── serve.ps1              שרת מקומי פשוט (PowerShell, לא חובה)
└── .claude/launch.json    קונפיגורציית שרת לתצוגה מקדימה בכלי הפיתוח
```

## איך מריצים

**האפשרות הכי פשוטה (מומלץ להתחלה):**
פשוט לחצו פעמיים על `index.html` — הוא ייפתח ישירות בדפדפן (כרום/אדג'/פיירפוקס) ויעבוד באופן מלא, כי אין קריאות רשת (fetch) לנתונים חיצוניים, הכל טעון מקבצי JS מקומיים.

**אפשרות שנייה — שרת מקומי (מומלץ אם בהמשך תחברו API אמיתי):**
במחשב הזה אין Node.js או Python מותקנים, אז הכנתי שרת סטטי זעיר ב-PowerShell (מובנה בווינדוס, לא דורש שום התקנה):

```bash
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

ואז פותחים בדפדפן: `http://localhost:5500`

לעצירה — `Ctrl+C` בחלון ה-PowerShell. אם הפורט תפוס, אפשר: `.\serve.ps1 -Port 5510`.

> טיפ: אם בעתיד תתקינו VS Code, התוסף **Live Server** נותן את אותה חוויה בלחיצת כפתור אחת, כולל רענון אוטומטי בכל שמירה — שווה שדרוג כשתתחילו לערוך קוד הרבה.

## איך עובדים עם הדאשבורד

- **חיפוש** — תיבת הטקסט מסננת לפי מספר פנייה, נושא, שם לקוח או אימייל (עם דיליי קצר כדי לא לרנדר על כל תו).
- **סינונים** — סטטוס, עדיפות, קטגוריה, נציג וטווח תאריכים (7/30/45 ימים או הכל) ניתנים לשילוב יחד. כפתור "איפוס סינון" מחזיר הכל לברירת המחדל.
- **מיון טבלה** — לחיצה על כותרת עמודה ממיינת לפיה; לחיצה נוספת הופכת כיוון (חץ ▲/▼ מציין את הכיוון הנוכחי).
- **פרטי פנייה** — לחיצה על שורה בטבלה פותחת חלון עם ציר זמן מלא (נפתחה → תגובה ראשונה → נפתרה) וסטטוס SLA.
- **עמידה ב-SLA** — מחושבת אוטומטית: כל פנייה מקבלת יעד שעות לפי עדיפות (דחופה=4, גבוהה=8, בינונית=24, נמוכה=48), וסטייה ממנו מסומנת ב-⚠ בטבלה ונספרת בכרטיס ה-KPI.
- **מצב כהה/בהיר** — הכפתור "🌓 מצב תצוגה" בפינה השמאלית העליונה; הבחירה נשמרת בדפדפן (localStorage) לפעם הבאה.
- כל תצוגות הדאשבורד (KPIs, גרפים, טבלה, ביצועי נציגים) **מגיבות לסינון בזמן אמת** — הן תמיד משקפות רק את מה שנבחר כרגע בפילטרים.

## טיפים לעבודה יעילה

1. **התחילו מ-`js/data.js`** אם רוצים לשנות את "העולם" של הדאשבורד — שמות נציגים, קטגוריות, טקסטים של פניות, כמות פניות (`TOTAL_TICKETS`), או טווח הימים (`RANGE_DAYS`). כל שאר הקבצים מגיבים אוטומטית לשינוי כי הם קוראים מהאובייקט `DASHBOARD_DATA`.
2. **אל תיגעו ב-`js/charts.js`** אלא אם צריך גרף חדש — הוא כתוב כמודול עצמאי עם 3 פונקציות (`renderLineChart`, `renderHBarChart`, `renderDonutChart`) שכל אחת מקבלת container ונתונים גנריים, כך שאפשר לעשות reuse בלי לגעת בלוגיקה.
3. **שינויים בעיצוב** — כל הצבעים מוגדרים כמשתני CSS ב-`:root` בראש `css/styles.css`. שינוי `--primary` למשל ישנה את כל הצבע הראשי בכל הדאשבורד בבת אחת.
4. **בדיקה מהירה אחרי כל שינוי** — פשוט רעננו (F5) את הדפדפן; אין שלב build/compile.
5. **פתחו את כלי הפיתוח של הדפדפן (F12) → Console** אם משהו לא מוצג נכון — כל שגיאת JS תופיע שם עם שם הקובץ והשורה המדויקים.
6. שימו לב ש-**`js/data.js` נטען לפני `js/app.js`** בתוך `index.html` — אם תוסיפו קובצי JS חדשים, שמרו על סדר הטעינה (data → charts → app), אחרת תיפול שגיאת "undefined".

## חיבור נתונים אמיתיים בעתיד

כרגע כל הנתונים הם דמו קבוע שנוצר ב-`js/data.js` (עם RNG "זרוע" כדי שהתוצאה תהיה עקבית בכל טעינה). כשתרצו לעבור לנתונים אמיתיים, שתי אפשרויות נפוצות:

- **קובץ CSV/JSON מהמערכת שלכם** — ייצוא מהמערכת הקיימת, וטעינה שלו ב-`app.js` עם `fetch('data/tickets.json')` (זה כבר ידרוש הרצה משרת מקומי, לא פתיחת קובץ ישירה, כי `fetch` על `file://` חסום בדפדפנים).
- **חיבור API** (Zendesk / Intercom / HubSpot וכו') — יחליף את מערך `TICKETS` בקריאת רשת אסינכרונית. המבנה של כל טיקט (`id`, `subject`, `status`, `priority`, `category`, `agentId`, `createdAt`, `resolvedAt`, `satisfaction` וכו') ב-`js/data.js` הוא בדיוק הסכימה שצריך למפות אליה נתונים חיצוניים.

בשני המקרים — ברגע שיש `fetch`, כבר לא ניתן לפתוח את `index.html` ישירות מהכונן; יש להריץ דרך `serve.ps1` (או Live Server) כדי לעקוף את חסימת ה-CORS של הדפדפן על קבצים מקומיים.
